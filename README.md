# Salutis — Plataforma Digital de Acolhimento, Triagem e Gestão de Espera Hospitalar
O **Salutis** é uma solução digital de autoatendimento e triagem integrada desenhada para eliminar filas desorganizadas, reduzir a morosidade no acolhimento inicial e oferecer previsibilidade em tempo real no pronto atendimento hospitalar, humanizando a jornada do paciente — especialmente idosos com mobilidade reduzida ou doenças crônicas.
